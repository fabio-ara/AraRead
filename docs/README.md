# Documentação por objetivo

A evolução 0.5 em validação está descrita no [guia de uso](guia-uso.md): autoria em quatro etapas, edições compartilhadas e leitura autônoma pelo site. A biblioteca anterior e o painel de três abas continuam disponíveis. O [STATUS](../STATUS.md) distingue implementação em desenvolvimento, versão publicada e provas efetivamente observadas.

O AraRead conserva uma biblioteca e o percurso de leitura para que uma interrupção não obrigue a reconstruir a conversa anterior. A fonte determina a ordem; o assistente acrescenta uma mediação identificada.

| Objetivo | Percurso |
|---|---|
| Entender a experiência e seus compromissos | [Produto e modelo de leitura](produto.md) |
| Importar, ler, perguntar e retomar | [Guia de uso](guia-uso.md), [fontes e formatos](fontes-formatos.md) |
| Usar um assistente conectado | [Conectar o assistente](conectar-assistente.md), [contrato MCP](contrato-mcp.md) |
| Instalar ou publicar uma instância | [Instalação](instalacao.md), [segurança](seguranca.md) |
| Recuperar falhas, conflitos ou dados | [Operação e recuperação](operacao.md) |
| Alterar o código e conferir o resultado | [Arquitetura](arquitetura.md), [testes e matriz](testes.md) |
| Conferir os incrementos F01–F10 e limites de aprendizagem | [Evolução e rastreabilidade](evolucao.md) |
| Conhecer decisões, fontes e limites | [Decisões e referências](decisoes.md), [STATUS](../STATUS.md) |

Evidências de versões anteriores permanecem identificadas como históricas. Progresso, notas, grifos e respostas são pessoais mesmo em edições públicas. A documentação e as fixtures não contêm obras pessoais ou credenciais. O [estado atual](../STATUS.md) distingue código, prova local, hospedagem e cliente externo.
